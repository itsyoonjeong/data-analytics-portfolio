## DataCamp Associate Data Analyst in SQL

### Overview

This folder contains my work for the DataCamp Associate Data Analyst in SQL certification.
The materials include both the sample practical exam and the certification practical exam.

### Dataset

The practical exam uses a dataset containing product sales information.

Key columns include:
- `product_id` – unique identifier of the product
- `product_type` – product category
- `brand` – product brand
- `weight` – product weight
- `price` – product price
- `average_units_sold` – average number of units sold per month
- `year_added` – year the product was added to inventory
- `stock_location` – warehouse location

### Tasks Covered

The certification exam involves several common SQL operations:
**1. Identifying missing values
2. Data cleaning and validation
3. Calculating summary statistics
4. Filtering data based on business conditions**
